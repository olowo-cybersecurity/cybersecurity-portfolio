Linux Firewall Configuration Using UFW

Project Overview

This project demonstrates how to configure and manage a Linux firewall using Uncomplicated Firewall (UFW)

Objective

To improve Linux system security by controlling incoming and outgoing network traffic.

Tools Used

Linux

UFW

Terminal

Practical Activities

1. Check firewall status.
2. Enable UFW.
3. Configure firewall rules.
4. Allow SSH traffic where required.
5. Deny unnecessary incoming connections.
6. Verify firewall configuration.

Commands Used

sudo ufw status

sudo ufw enable

sudo ufw allow 22/tcp

sudo ufw deny 23/tcp

sudo ufw status numbered

Security Outcome

The exercise demonstrates basic firewall administration and network access control.
